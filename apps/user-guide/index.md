## このガイドについて

Library の Web 画面でできることの多くは、API からも実行できます。このガイドは、
API キーを発行し、REST または GraphQL でリポジトリのデータを扱うまでの手順を
まとめたものです。

- [はじめに](/api/getting-started) — 3 ステップで最初のリクエストを送る
- [API キーの発行と失効](/api/api-keys) — キーのライフサイクルと取り扱い
- [REST API](/api/rest) — データの一覧・取得・作成・更新・削除・エクスポート
- [GraphQL API](/api/graphql) — 単一エンドポイントでの問い合わせと、キー利用時の注意
