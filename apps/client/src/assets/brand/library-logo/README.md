# Library logo assets

The production source files in this directory are deterministic SVG redraws of
the selected two-node Earth knowledge-network concept. The hookless mark was
confirmed as the final direction. Flat colors and a consistent negative-space
channel keep it crisp at different sizes.

## Variants

- `master.svg`: canonical two-color mark.
- `streamlined.svg`: lighter-weight alternate.
- `ring-forward.svg`: stronger outer ring and lighter orbit.
- `app-icon.svg`: heavier small-size treatment.
- `monochrome.svg`: one-color print and embossing source.
- `reverse.svg`: dark-background treatment.

## Palette

- Navy: `#07172f`
- Blue: `#1557ff`
- Reverse blue: `#4d7cff`
- White: `#ffffff`

The confirmed raster reference is `generated/00-selected-final.png`. Other
generated raster explorations are kept beside it for design history. Raster
exports from the deterministic SVG sources are kept under `png/`.
