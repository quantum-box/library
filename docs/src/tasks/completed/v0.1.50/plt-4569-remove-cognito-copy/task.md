# PLT-4569 — ログイン画面から Cognito 説明文を削除

## 概要

Library Client のログインフォーム下部に表示していた、認証プロバイダーと
アカウント作成・復元を説明する文言を削除する。認証処理、Cognito 接続設定、
セッション管理は変更しない。

## 関連

- Linear: [PLT-4569](https://linear.app/issue/PLT-4569)
- リリース対象: Library Client `0.1.50`（`origin/main` の `0.1.49` から patch bump）

DD / ADR は作成しない。既存認証フローを変更しない表示文言の削除であり、
永続仕様やアーキテクチャ判断を追加しないためである。

## 実装

- `AuthGate` から Cognito 説明段落を削除した。
- 不要になった `auth.cognitoNote` を全11言語のカタログから削除した。
- 認証プロバイダー名がログイン画面へ再表示されない単体テストとE2Eを追加した。

## 検証

- Red: 追加した `AuthGate` テストが既存の Cognito 説明段落を検出して失敗することを確認
- Green: `AuthGate` と翻訳キーの削除後、対象単体テストとカタログテストが47件成功
- Chromium未ログインE2E: 1件成功。外部Cognitoリクエストは送信していない
- `npm run lint`: 成功（既存の `TableView.tsx` 警告1件のみ）
- `npm run build`: 成功
- クライアント全体テスト: 並列実行時の高負荷下で無関係な複数テストが10秒 timeout
  となり、7分超で完了していなかったため中断。timeout した4ファイルを個別に再実行し、
  46/46件成功（変更前ベースでの全体実行では631/633件まで成功し、残る2ファイルも
  個別再実行で23/23件成功）。CI の全体テストを残存ゲートとする
- `git diff --check`: 成功

## 完了条件

- ログイン画面に Cognito 説明文が表示されない。
- 認証処理に変更がない。
- 表示契約を保護する単体テストとE2Eが成功する。
